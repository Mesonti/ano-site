# Сайт АНО «Цифровой аудит»

Статический сайт АНО «Цифровой аудит». Проект собран на чистых HTML, CSS и JavaScript без сборщика и внешних npm-зависимостей.

## Структура проекта

- `index.html` — разметка страницы и SEO-метатеги.
- `styles.css` — стили, адаптив, анимации и визуальные состояния.
- `script.js` — интерактив: аккордеоны, фиксированная навигация, scroll-анимации, появление элементов.
- `img/` — изображения, SVG-иконки и оптимизированные responsive-версии.
- `fonts/` — локальные шрифты Golos Text.
- `docs/` — PDF-документы для скачивания.
- `robots.txt` — правила индексации.
- `sitemap.xml` — карта сайта для поисковиков.

## Локальный запуск

Проект можно открыть напрямую через `index.html`, но лучше запускать через локальный сервер, чтобы корректно работали пути, кеширование и проверки Lighthouse.

```bash
python3 -m http.server 8000
```

После запуска открыть:

```txt
http://localhost:8000/
```

## Работа с изображениями

В проекте используются responsive-изображения через `srcset` и `picture`.

Важно:

- не заменять оптимизированные файлы оригиналами без необходимости;
- для тяжёлых фонов использовать AVIF + PNG fallback;
- для маленьких декоративных иконок добавлять версии под реальный размер отображения;
- после замены изображений прогонять Lighthouse, особенно раздел `Image delivery`.

## Шрифты

Шрифты подключены локально из папки `fonts/` через `@font-face`.

Используются веса:

- `400` — Regular;
- `500` — Medium;
- `600` — DemiBold.

Google Fonts не используется, чтобы уменьшить внешние запросы и render blocking.

## Навигация и интерактив

На странице есть обычная hero-навигация и фиксированная навигация, которая появляется при скролле. Важно следить, чтобы скрытая навигация не попадала в Tab-порядок. Для этого используются `aria-hidden` и `inert`.

Аккордеоны компетенций:

- открываются по клику на всю карточку;
- поддерживают `aria-expanded` и `aria-controls`;
- в закрытом состоянии используют локальную иконку `arrow-down-right.svg`;
- в открытом состоянии используют `expand-icon.svg`.

## Доступность

Перед публикацией изменений желательно проверить:

- контраст текста и кнопок;
- работу навигации с клавиатуры;
- отсутствие фокуса на скрытых элементах;
- корректность `alt`, `aria-label`, `aria-hidden`;
- отсутствие горизонтального скролла на мобильных ширинах.

```bash
python3 -m http.server 8000
```

## Важные замечания для разработчиков

- Проект без сборщика, поэтому изменения сразу вносятся в `index.html`, `styles.css`, `script.js`.
- CSS большой и секционный: перед правкой лучше искать нужный блок по классу секции.
- Не удалять оптимизированные варианты изображений, если они указаны в `srcset`.
- После изменения CSS/JS обновлять query-version в `index.html`, если нужно сбросить кеш у открытой страницы.
- Документы в `docs/` должны иметь понятные человекочитаемые имена, так как они доступны пользователям напрямую.
